# VANTAGE

Official implementation of "VANTAGE: Viewpoint-Aware Navigation with
Terrain-Adaptive Guidance" (Robotics: Science and Systems 2026).

The archive ships the complete training and evaluation code used for the paper,
including the viewpoint selector and the terrain-adaptive guidance policy.

## Layout

- `vantage/` - policy, terrain model and viewpoint selector
- `scripts/` - train / evaluate entry points
- `configs/` - experiment configurations
